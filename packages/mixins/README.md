# foldkit-mixins

Typed slot contracts and inside-out Style/Behavior attachments for Foldkit.

A view publishes the structural points it is willing to customize. Style and
Behavior attach to those points. Application state stays in the Foldkit
Model; this package does not own a second runtime.

Private while the API is settling (`0.0.0`). See [DESIGN.md](./DESIGN.md).
